# SNAP — 結婚式場向けフォトブース

**所属・関係:** Introduction Inc.

**担当領域:** プロダクト開発・営業・サポート

**期間:** 確認できた開発履歴：2022年12月〜2024年10月（公開・提供期間は未確認）

## 概要

結婚式場向けのB2Bフォトブースサービスで、イベント管理、ゲスト向けアルバム、会場スクリーンを開発。確認したソースはNext.js、React、TypeScript、FirebaseとSalsa API連携を使用しています。UI設計、実装、営業、導入支援、サポートまで担当しました。確認できた開発履歴は2022年12月〜2024年10月で、公開・提供期間や在籍期間を示すものではありません。

## 技術

TypeScript, React, Next.js, Firebase, Mantine, Salsa API
