# FalconeXコーポレートサイト

**所属・関係:** FalconeX

**担当領域:** Webサイト開発・保守

## 概要

会社情報の更新と問い合わせ対応を共通の構成で管理するため、WordPress／PHPの独自テーマを開発。Markdownからのページ生成、メタデータ検証、JavaScriptによるフォームエラー表示とフォーカス移動を実装しました。不正・重複するページ情報を検出し、問い合わせ時には修正が必要な入力項目へ案内します。

## Overview

FalconeX corporate website

**Context:** FalconeX

**Role:** Website development and maintenance

Built a custom WordPress/PHP theme so company pages and inquiry interactions could share a maintainable content structure. Implemented Markdown-driven pages, metadata validation and JavaScript form errors with focus handling. The theme rejects invalid or duplicate page metadata and guides users to inquiry fields that need correction.

## 技術 / Stack

WordPress, PHP, JavaScript, Markdown
