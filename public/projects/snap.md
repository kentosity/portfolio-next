# SNAP — 結婚式場向けフォトブース

**所属・関係:** Introduction Inc.

**担当領域:** アプリ開発・UI設計

## 概要

Introductionで、式場スタッフのイベント管理とゲストの写真閲覧をつなぐフォトブース用アプリを開発。Next.js、TypeScript、Firebase、Salsa APIでイベント設定、ゲスト向けアルバム、会場表示を実装しました。

## Overview

SNAP — wedding photobooth product

**Context:** Introduction Inc.

**Role:** Application development and interface design

Developed connected applications for venue staff and wedding guests to manage photobooth events and view captured photos at Introduction. Built event settings, guest albums and venue displays with Next.js, TypeScript, Firebase and the Salsa API.

## 技術 / Stack

TypeScript, React, Next.js, Firebase, Mantine, Salsa API
