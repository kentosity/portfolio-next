# 補助金検索AIアシスタントのプロトタイプ

**所属・関係:** 個人の開発プロジェクト

**担当領域:** プロトタイプ開発

## 概要

事業者の資金ニーズから補助金の検索条件を整理し、候補と出典を示すローカルAIプロトタイプを開発。TypeScript／Reactの画面、言語モデルとの対話処理、Playwrightの検索キューを接続しました。サーバー側で検索条件、候補ID、出典の抜粋を検証。

## Overview

AI subsidy-search assistant prototype

**Context:** Independent project

**Role:** AI search prototype and application development

Built a local AI prototype that turns a business’s funding needs into subsidy-search conditions and source-linked candidate explanations. A TypeScript/React workspace connects a language-model conversation layer to a queued Playwright search worker. Server checks validate conditions, candidate IDs and source excerpts.

## 技術 / Stack

TypeScript, Node.js, React, Playwright
