# i+i — 建築事務所ポートフォリオ

**所属・関係:** 個人開発

**担当領域:** Webデザイン・開発

## 概要

建築事例の紹介と継続的な更新を両立するため、WordPress／Sageのテーマを開発。PHP／BladeとJavaScriptで編集用のカスタムブロックを実装しました。見学会は開催予定がない場合に直近の事例を表示。問い合わせ時のフォーカス移動や、動きを減らす設定に対応した一時停止可能なヒーロー表示も整備しました。

## Overview

i+i — architecture portfolio website

**Context:** Independent project

**Role:** Web design and development

Developed a WordPress/Sage theme for an architecture portfolio, combining project presentation with an editor workflow for ongoing updates. Built custom blocks with PHP/Blade and JavaScript, plus an open-house listing that falls back to recent events when none are upcoming. Added inquiry-form focus handling and a pausable hero carousel that respects reduced-motion settings.

## 技術 / Stack

WordPress, Sage, PHP, Blade, JavaScript, Tailwind CSS, Vite
